### 🧪 Testing Types & Levels

- **Manual & Exploratory Testing:** Test scenario mapping, test case creation and execution, detailed bug reporting.
- **API / Backend Testing:** Endpoint validation, status codes, payloads, and contract testing in REST architectures.
- **Web & Mobile Testing:** UI validation, usability, responsiveness, and regression testing.
- **Quality Management:** Test plan development, acceptance criteria definition, and bug life cycle tracking.
